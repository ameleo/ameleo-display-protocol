# Security policy

The interfaces carry the user's clipboard, files, print jobs and camera streams between a guest
and its host. If you find a weakness in their design, such as data that a peer can be tricked
into accepting, please report it privately through GitHub: on the repository page, open the
**Security** tab and choose **Report a vulnerability**. Do not open a public issue. If you cannot
use GitHub, write to opensource@ameleo.fr.

Please report vulnerabilities in a specific agent or host implementation to that project.

Include what you found, how to reproduce it and its impact as you understand it. We will
acknowledge the report and keep you informed of the fix.
